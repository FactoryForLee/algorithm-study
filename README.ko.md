# 알고리즘 스터디

[English](README.md) | **한국어**

공부한 알고리즘과 자료구조를 정리하는 레포지토리입니다.
알고리즘 하나마다 Visual Studio 프로젝트 하나로 구현했습니다.

## 사용 기술

- 언어: C++
- IDE: Visual Studio

## 폴더 구조

```
algorithm-study/
├── algorithm-study.sln   # 모든 프로젝트를 묶는 솔루션
├── QuickSort/            # 알고리즘마다 프로젝트 하나
│   ├── QuickSort.vcxproj
│   └── main.cpp
└── BFS/
    ├── BFS.vcxproj
    └── main.cpp
```

## 실행 방법

1. Visual Studio에서 `algorithm-study.sln`을 엽니다.
2. 실행할 프로젝트를 우클릭 → **시작 프로젝트로 설정**을 누릅니다.
3. `Ctrl + F5`로 빌드하고 실행합니다.
