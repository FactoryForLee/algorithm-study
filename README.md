# Algorithm Study

**English** | [한국어](README.ko.md)

A personal repository for organizing algorithms and data structures I've learned.
Each algorithm is implemented as a separate Visual Studio project.

## Tech

- Language: C++
- IDE: Visual Studio

## Structure

```
algorithm-study/
├── algorithm-study.sln   # Solution containing all projects
├── QuickSort/            # One project per algorithm
│   ├── QuickSort.vcxproj
│   └── main.cpp
└── BFS/
    ├── BFS.vcxproj
    └── main.cpp
```

## How to Run

1. Open `algorithm-study.sln` in Visual Studio.
2. Right-click the project you want to run → **Set as Startup Project**.
3. Press `Ctrl + F5` to build and run.
